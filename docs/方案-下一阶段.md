## 2. 范围（冻结）

### 做

**A. 视觉打磨（项目库 + 编辑器壳）**

- 项目库：渐变头图区、卡片 hover、图标操作更明显、空状态插画式色块  
- 编辑器：左上「返回项目库」与状态胶囊统一成一条工具条风格  
- 不改 M3 组件绘制内核（M3Node）除非明显 bug  

**B. 多设备 P1**

- `FramePreset` 增加 `"tablet"` → 834×1112  
- 屏幕标签 / 菜单可选平板  
- AI 设备选项：手机 / 平板 / 桌面 / 双端（手机+桌面）或手机+平板  
- `draftDesign` 提示词写入设备家族导航规则  
- design-system 检查清单已在 v0.2；代码对齐即可  

**C. 文档**

- 本方案、PROGRESS、DECISIONS 补一条「多设备已确认」  
- 工程规范：每阶段结束必须更新 docs/README 索引  

### 不做（仍冻结）

- 个人样式库大功能（阶段 3）  
- 图标资源库（阶段 4）  
- 多设计系统 Pack（阶段 5）  
- 同步/登录（阶段 6）  
- Tauri（阶段 7+）  
- 多方案并排 AI 挑选（可记 backlog）
