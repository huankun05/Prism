## 1. 目标与非目标

### 目标

1. **项目列表**：浏览 / 新建 / 打开 / 重命名 / 删除  
2. **工作区文件夹**：项目真实落在用户磁盘上，可备份  
3. **自动保存** + 状态提示  
4. **导入/导出 JSON**；旧 localStorage 草稿可迁移  
5. **全浏览器可用底线**；Chromium 体验完整  

### 非目标

登录、云同步、MCP、个人样式、封面图、标签搜索、多人协作、改 M3 绘制与提示词内核。

---

## 2. 调研带来的设计选择（不是拍脑袋）

| 选择 | 推荐 | 依据 |
|------|------|------|
| 存储位置 | 用户选择的 **Prism 工作区** 文件夹 | Obsidian「库=文件夹」；数据归用户 |
| 项目粒度 | 工作区下 **每个子文件夹 = 一个项目** | 多项目管理；一次授权长期用 |
| 主 API | `showDirectoryPicker`（用户可见 FS） | OPFS 用户不可见，不能当主存储 |
| 无 FSA | 降级：导出/导入 + 草稿 + 最近 | Safari/Firefox 无该 API（约 24%） |
| 保存 | **默认自动保存**（防抖） | Excalidraw / tldraw 同类惯例 |
| 旧数据 | **提示导入**，不静默覆盖 | 鲁棒、可预期 |
| 句柄记忆 | IndexedDB 存目录 handle | 刷新后少点授权；localStorage 不够 |

## 3. 用户流程

```
首次打开
  → 项目库页（空态引导）
  → 「选择工作区文件夹」或「新建项目」（自动先选工作区）
  → 授权目录
  → 创建 项目名/design.json + meta.json
  → 进入画布，自动保存

日常
  → 打开 Prism → 项目库（或记住上次？见下）
  → 点项目 → 画布编辑 → 自动写回
  → 返回项目库

无文件夹能力的浏览器
  → 项目库显示：说明 + 导入 JSON + 打开浏览器草稿
  → 仍可导出下载 design.json
```

**上次打开：** 阶段 1 **不做**自动恢复上次项目（减少状态复杂度）；每次都从项目库进，或提供「继续上次」若实现成本低则作为「应该」项。

## 4. 磁盘布局

```
<用户选择的工作区>/
  .prism-workspace.json     # 可选：{ "app": "prism", "schema": 1 }
  食谱App/
    design.json             # 现有 Doc
    meta.json               # 元数据（见下）
  设置页草稿/
    design.json
    meta.json
```

**meta.json**

```json
{
  "schema": 1,
  "app": "prism",
  "name": "食谱App",
  "note": "",
  "updatedAt": "2026-09-15T12:00:00.000Z"
}
```

缺 meta：用 `design.title` 与文件时间兜底。

**为什么不把所有项目塞一个大 JSON：** 文件级备份、git、外部编辑更友好（调研：开放格式/单项目文件）。

## 5. 功能范围（冻结）

### 必须（DoD）

1. 工作区选择与授权（Chromium）  
2. 项目 CRUD：新建、打开、重命名、删除（确认）  
3. 打开后画布 = 原有 Editor，挂自动保存  
4. 保存状态：已保存 / 保存中 / 失败重试  
5. 导入 .json 为新项目；导出仍用现有 saveProject  
6. 旧草稿迁移提示  
7. 无 FSA 降级页  
8. 非法文件错误，不崩溃  
9. typecheck / test / build 绿；更新 PROGRESS  

### 应该（时间允许）

- IndexedDB 持久化工作区 handle  
- 降级模式「最近打开」（内存/localStorage 列表）  
- 「继续上次」按钮  

### 明确不做

封面、搜索、嵌套目录、同步、多选删除、OPFS 主存储。

## 6. 技术结构

```
lib/storage/
  types.ts           # ProjectMeta, WorkspaceInfo
  detect.ts          # supportsDirectoryPicker()
  meta.ts            # 合并/排序/默认值（纯函数，单测）
  workspace.ts       # 打开工作区、列项目、CRUD（FSA）
  handleCache.ts     # IndexedDB 缓存 DirectoryHandle
  fallback.ts        # 无 FSA：最近列表 + 文件导入导出包装
  migrate.ts         # 旧 m3e 草稿 → 新项目
components/
  ProjectLibrary.tsx # 项目库 UI
  SaveStatus.tsx     # 保存状态
app/
  page.tsx           # 库 / 画布 切换
app/Editor.tsx       # 小改：接收已加载 Doc、暴露 onChange 回调或受控保存
```

原则：

- FSA 与 UI 隔离，便于 mock 测试  
- Editor 尽量「输入 Doc + 通知保存」，少塞业务  
- 复用 `isProject` / `saveProject` 逻辑

## 7. 自动保存细节

| 项 | 值 |
|----|-----|
| 触发 | Doc 结构变更（groups/frames/theme…） |
| 防抖 | ~500ms（实现时可配 400–800） |
| 写入 | `design.json` + 更新 `meta.updatedAt` |
| 失败 | 状态变红 + 重试；不丢内存态 |
| 关闭页面 | 尽力 flush（visibilitychange / beforeunload 尽力而为） |
