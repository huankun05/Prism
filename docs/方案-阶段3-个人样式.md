## 0. 阶段 3 解决什么

阶段 2 已有：**内置风格预设 + 用户自定义预设（存/导/导）**。  
还缺 D6 真正的「产品级」个人样式：

| 层 | 现状 | 3 要做的 |
|----|------|----------|
| **系统层** | STYLE_PRESETS 固定 | 保持只读；可扩展入口清晰 |
| **个人层** | 仅 localStorage 预设卡片 | **完整个人样式档案**：默认主题、默认设备、默认风格、收藏图标、备注 |
| **项目层** | Doc 内 palette/theme | 不变；可「从个人样式初始化」「存回个人样式」 |

同时补体验：**样式入口不只藏在 AI 面板**，主题/默认值与个人档案打通。

---

## 1. 目标（做完能感到）

1. 有「**我的样式**」档案：新项目默认可套用  
2. 当前画布主题 → **一键存入我的样式**；我的样式 → **应用到当前项目**  
3. 系统预设与个人预设在 UI 上分组清楚（内置 / ★我的）  
4. 个人样式可 **导出/导入 JSON**（已在预设上，扩展到完整档案）  
5. 仍 **不强制登录、不云同步**（阶段 6）

---

## 2. 范围冻结

### 做

**A. 数据模型 `lib/personalStyle.ts`**

```ts
type PersonalStyle = {
  schema: 1;
  id: string;
  name: string;              // 默认 / 主档案名
  paletteKey: string;
  theme: Theme;              // 完整 Theme
  stylePresetId?: string;    // 关联内置/自定义预设 id（可选）
  defaultDevice?: "phone" | "tablet" | "desktop" | "both";
  defaultPlatform?: "android" | "web";
  favoriteIcons?: string[];  // 图标收藏（后续资源库用，先存）
  updatedAt: string;
};
```

- 存储：`localStorage` `prism:personal-style`  
- 纯函数：normalize / validate / merge，**单测**

**B. UI**

1. **设置入口**：主题面板或 AI 工作台旁增加「我的样式」  
   - 显示当前档案摘要  
   - 按钮：从当前画布保存 / 应用到画布 / 导出 / 导入 / 重置  
2. **新建项目**：若存在个人样式，可选「用我的样式初始化」（默认勾选可配置）  
3. **预设区** 分组标题：`我的档案` / `我的预设` / `内置风格`

**C. 与编辑器接线**

- `page.tsx` 新建项目时读个人样式写入初始 Doc 的 palette/theme  
- 不改变 Bridge/MCP 协议

### 不做

- 云同步、账号（阶段 6）  
- 多套个人档案管理（只 1 份主档案；多档案可 backlog）  
- 图标库 UI（阶段 4；favoriteIcons 仅字段预留）  
- 多设计系统 Pack（阶段 5）
