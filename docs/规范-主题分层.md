# 界面主题 vs 项目主题（调研结论）

> 依据：Figma、VS Code、Photoshop 等设计/开发工具的通行做法。

## 规则（我们采用）

| 层 | 包含 | 是否跟项目变 |
|----|------|----------------|
| **编辑器外壳（Chrome）** | 左右侧栏、工具栏、对话框、返回条、模式提示 | **否**。自带浅/深主题，在 **设置** 里改 |
| **文档 / 画布内容** | 手机框内的组件、色板、圆角、暗色设计稿 | **是**。风格预设、颜色面板、Pack 只影响这里 |
| **预览 / 提示词** | 点按预览、导出 Prompt | 跟 **文档** 主题 |
| **应用自身 Logo/加载页** | 启动动画、项目库 | **独立品牌色**，不跟项目 |

## 为什么

- Figma：Interface theme 与 file 内 fill/style 分离  
- VS Code：Workbench theme ≠ 文件里的颜色  
- 混在一起会导致「选个粉色设计，工具栏也变粉」——专业工具不这么做  

## 实现落点

- `ui`：编辑器外壳色板（默认浅色中性，可后续加设置项 dark chrome）  
- `p` / `paletteOf(paletteKey, …)`：仅画布与导出
